## Resumo por ambiente

| Ambiente | Solução Fast |
|---|---|
| Parede interna seca | Drywall placa ST + montante/guia + lã + massa/fita |
| Área úmida (banheiro/cozinha) | Placa RU (interna) / cimentícia (revestida) |
| Fachada / externo | Steel Frame + Glasroc X ou Aquapanel + membrana + malha + basecoat |
| Forro escritório/escola/hospital | Forro acústico (Ecophon) modular |
| Piso residencial | Piso vinílico Vita / Massima Home / Città Home (classe 21, 10 anos) |
| Piso comercial intenso | Massima Pró / Città Pró (capa 0,55 mm, classe até 42) |
| Casa nova rápida | Steel Frame / Fast Homes (casa modular) |

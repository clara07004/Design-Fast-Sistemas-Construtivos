## Lógica de código (SKU normatizado)

Prefixos observados no Catálogo de Produtos: **DW** = drywall (montante/guia/perfil/regulador/massa/placa), **FF** = perfil de forro/acabamento, **FR** = regulador de forro. Ex.: Montante M48 = `DW00086`; Guia G48 = `DW00012`; Perfil F530 = `DW00032`; Cantoneira 14×30 = `FF00048`.
